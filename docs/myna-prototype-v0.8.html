Myna · 产品原型 v0.8

Myna · 听听大家怎么说 — 给万事万物打分的轻社交

核心玩法

  • 产品评价：在超市看到新口味可乐？拍照发帖提问，大家用五档（屎 / 不好喝 / 一般 / 好喝 / 顶级）投票 + 一句话说明理由。
  • 事件评价：早八去不去、团建值不值——把纠结发出来，用「去 / 不去」量表让大家帮你拿主意。
  • 榜单系统：月榜（每月结算）+ 总榜（历史累计），按饮料 / 食品 / 事件分类；最佳 Top 20 与踩雷 Top 20 并列，好坏都被看见。

本轮更新（v0.8）

  • 导航重构（北美式）：底部改回 5 个——首页 / 附近 / 中央凸起发布 + / 榜单 / 我的；删除右侧贴边悬浮钮
  • 左侧隐藏抽屉：主 Tab 页顶栏点 ☰ 滑出——用户区（点头像区进「我的」）、链接识品、设置，及次级菜单成就 / 收藏 / 历史 / 草稿箱；识品与设置改为带返回键的独立页

v0.7 更新

  • 右侧悬浮发布 + 钮改为完整圆形内缩，不再被屏幕边缘挡住
  • 分类专属评价量表（中文 / English）：每个细分分类一套五档趣味文案，如饮料 👎一口皱眉→🤩吨吨吨、零食 🤩一包炫完、电子产品 😖智商税→🤩闭眼入、情感 😒下头→😍锁死、教育 🤩听君一席；详情分布条、评价弹窗、评论徽章、榜单详情全线同步，其余 5 种语言沿用通用量表
  • Logo 融合设计：八哥栖在 M 的右肩上、喙微张学舌，长尾化作字标下方的弧线，在红色 a 处收尾

v0.6 更新

  • 品牌正式定名 Myna（八哥）：学人说话的鸟——你问一句，它把大家的声音学回来给你听。首页 Logo 换成八哥图标 + Myna 字标，设置页关于组同步更新，版本升至 v0.6.0
  • Slogan：「Myna · 听听大家怎么说」；品牌名在 7 种 UI 语言下均保持原文不翻译

v0.5 更新

  • ① 底部导航改 6 Tab：首页 / 附近 / 榜单 / 链接识品 / 我的 / 设置——「附近」和「链接识品」从 + 菜单里独立出来
  • ② 发布改走右侧边悬浮 + 钮（半贴边），点一下直达发布页；浏览型页面（首页 / 附近 / 榜单 / 我的）才显示
  • ③ 「我的」重新编排：头像 + 信誉分并入头卡；新增「我的徽章」展示卡——3 枚已解锁奖牌横排 + 「+8 全部」，点任意处进成就页
  • ④ 链接识品走「路 B」：以系统分享的整段文案为数据形态，标题关键词匹配；识别不出如实提示，绝不编造

此前已上线（v0.2 – v0.4）

  • 修改评价限 3 次 + 「已编辑」小字；榜单行可点开详情；发布页产品/事件联动类别 + 真实 GPS 定位
  • 11 枚成就徽章墙 + 限时挑战 + 成就达人榜；7 语言 UI 全翻译 + 首页 🌐 内容多选过滤；深色模式；本周战报与常用功能
  • 设置页：顶部账户卡（第三方登录横排）+ 卡片分组，隐私组含可见范围 / 屏蔽名单 / 缓存大小

操作提示

· 点底部中央凸起 + 直接发帖；点顶栏 ☰ 打开左侧抽屉进「链接识品」贴示例链接识别产品，「附近」Tab 按半径看周边帖子
· 首页右上角 🌐 切换信息流语言，未全选时有角标
· 给任意帖子评一次，再进详情页试试「修改评价」
· 去榜单点任意一行，打开它的评价详情页
· 「我的」徽章卡点任意徽章进成就页；收藏 / 历史 / 草稿箱 / 关注都能点，草稿能续写到发布页

本原型为前端交互演示：数据为种子数据，评价 / 发布 / 设置即时联动，刷新后重置。
